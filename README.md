# The Randomizer 🎲

A small phone-friendly web app that decides who goes first. Pick how many players or teams there are, enter their names, and roll a die with one face per player.

Made for fun by Joey.

## Put it online with GitHub Pages
1. Create a new public repo on GitHub, e.g. `the-randomizer`.
2. Upload every file in this folder: `index.html`, `icon.svg`, `apple-touch-icon.png`, `manifest.webmanifest`, `README.md`.
3. In the repo, go to **Settings → Pages**. Under **Source**, choose **Deploy from a branch**, then pick `main` / `(root)` and save.
4. After a minute or so it's live at `https://<your-username>.github.io/the-randomizer/`.

## Add it to your home screen
- **iPhone:** open the link in Safari, tap **Share**, then **Add to Home Screen**.
- **Android:** open it in Chrome, tap **⋮**, then **Add to Home screen**.

It then opens full-screen like an app.
